CUSTOM DICE

Custom dN dice roller for unusual dice

Not every game uses only d4, d6, d8, d10, d12, d20, and d100. The CUSTOM control lets you enter an arbitrary numerical die from d2 through d1,000,000.

EXAMPLES

Roll d3, d7, d37, d1000, and more

Open CUSTOM, type a number such as 37 or d37, and roll. The result is always an integer from 1 through N, inclusive.

NO FAKE GEOMETRY

Custom dN does not pretend every die has a physical mesh

A physical d37 is not part of the standard RPG polyhedral set. Instead of showing misleading geometry, custom dN uses a numerical result path designed for arbitrary ranges. Standard tabletop dice keep the physical 3D engine; unusual dN stays explicit.

RANDOMNESS

Web Crypto with rejection sampling

Custom numerical dice use the browser's cryptographically secure random generator and rejection sampling so the mapping does not introduce modulo bias. Every integer from 1 through N is intended to have the same probability.

USE CASES

Useful for tables, generators, and homebrew systems

Custom dN is useful for random tables with unusual lengths, homebrew systems, procedural prompts, or any rule that literally asks for a die size your physical bag does not contain.

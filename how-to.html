HOW TO

Roll first. Customize only when you want to.

The core roller is intentionally fast: choose dice and roll. Accounts, shortcuts, custom appearances, and Community sets are optional layers.

Pick dice

CORE ROLLER

Standard dice, ADV/DIS, and Keep Dice

A

Standard dice use 3D physics

The seven standard tabletop dice use the app's DiceBox physics engine. The numerical result returned by the physics roll is authoritative.

B

ADV and DIS are instant d20 rolls

ROLL ADV rolls two d20s and keeps the higher result. ROLL DIS rolls two d20s and keeps the lower result. These quick rolls do not consume a dice pool you were building.

C

Keep Dice changes what happens after a roll

With Keep Dice on, the selected standard dice remain in the pool after rolling. With it off, the pool clears after the roll.

Default Dice is always available. It is the permanent system fallback and cannot be edited or deleted.
CUSTOM dN

Roll unusual dice such as d3, d37, or d1000

Open CUSTOM, enter a number such as 37 or d37, then roll. Custom numerical dice are supported from d2 through d1,000,000.

The app does not pretend a physical d37 mesh exists. CUSTOM dN uses the browser's Web Crypto random generator with rejection sampling so every result from 1 through N has equal probability.

DICE STUDIO

Make the dice yours without changing how they roll

From the main roller, choose Dice Studio in the top header. Dice Studio is the visual customization area for your standard RPG dice and tray. It is where you build, save, activate, lock, and optionally publish custom-looking dice sets.

You can change the color of the whole set or customize individual dice, turn dice glow on or off, change tray color and glow, add an optional tray image, and replace the visual marking on individual faces with a number, keyboard character, symbol, rune, icon, or short word.

  • Save Dice Set stores the current draft.
  • Use This Set makes a clean saved set the active appearance on the roller.
  • Reset to Default restores the permanent System Default without deleting your saved sets.
  • Lock Set freezes the design so it can be published safely.
  • Publish Set makes a locked copy available in Community. Other users can use the public copy but cannot edit your owned set.
  • Unsaved changes cannot be activated, locked, or published.
Visual faces never change results. If the logical 20 face is displayed as ☠, ★, CRIT, a rune, or another short label, it still rolls a numerical 20 underneath. RAW face mode always uses standard numbering.
Dice Studio does not change mechanics. It cannot change a die's number of sides, physical RPG shape, numerical odds, ADV/DIS behavior, shortcut math, critical-hit rules, or the result returned by the roller. It changes presentation only.

D100

Percentile faces stay canonical

The physical d100 mapping remains the standard percentile sequence 00 / 10 / 20 / … / 90. A custom visual label can replace what you see on a face, but it cannot change the logical percentile result.

  1. Save the set.
  2. Lock it. A public set must be locked.
  3. Publish it to Community.
  4. Other users can view/use the Community copy, but cannot edit or delete your owned set.

Public Community projections do not expose your account email or internal account ID. Public creator text is shown as Adventurer.

FAQ

Common questions

Can custom dice change my odds?

No. Appearance changes never alter standard die shapes or numerical semantics.

Can I lose Default Dice?

No. Default Dice is system-owned, locked, immutable, and always available as the fallback.

Why does a CUSTOM dN look different from a standard 3D die?

Because nonstandard shapes such as a d37 do not have a canonical physical mesh in the standard DiceBox set. The app shows the secure numerical result instead.

Where is my account data used?

See the Privacy page for browser storage, account sync, cloud sets, and Community publishing.

PERCENTILE PAIR

Two d10-style dice make a d100 result

A conventional percentile roll uses one die for tens and one for ones. The tens die shows 00, 10, 20, …, 90. Combined with the ones die, the pair covers one hundred possible results.

CANONICAL FACES

The physical mapping stays recognizable

Nothing But A Dice Roller preserves the canonical percentile face sequence for the physical d100. Visual customization can change what a logical face looks like, but the underlying percentile result remains numerical.

TABLE USE

Great for random tables and percentage checks

d100 is especially useful when a game expresses chances directly as percentages or when a GM uses a table with up to one hundred entries. Roll once, read the combined percentile result, and use that row.

DICE SET

The standard tabletop set

d4 is four-sided, d6 is the familiar cube, d8 has eight faces, d10 supports ten-sided rolls, d12 has twelve, and d20 has twenty. Percentile d100 uses the standard tens-style d10 mapping alongside a ones die.

MIXED POOLS

Build the roll your game asks for

Tap a die multiple times to add quantity, mix different standard dice, and roll the pool together. Keep Dice can leave the selected pool ready for another roll when you are repeating the same action.

D20 TOOLS

Advantage and disadvantage are one action

Dedicated ADV and DIS controls handle the common two-d20 keep-highest / keep-lowest pattern without changing the rest of your current dice pool.

TRUST & RANDOMNESS

How our dice randomness works

A dice roller is only useful if its result path is understandable. Nothing But A Dice Roller deliberately separates standard physical dice from arbitrary custom numerical dice instead of pretending they are the same system.

STANDARD DICE

The 3D physics roll is authoritative

For d4, d6, d8, d10, d12, d20, and percentile d100, the standard physical dice engine produces the numerical result. The visible roll is therefore tied to the answer the application reports.

CUSTOM dN

Arbitrary ranges use Web Crypto

For unusual numerical dice such as d37, the app uses Web Crypto and rejection sampling. Rejection sampling avoids the uneven mapping that can happen when an arbitrary random integer is reduced with naïve modulo arithmetic.

VISUAL SAFETY

Appearance never rewrites the logical face

If you replace the visible logical 20 face with a skull, rune, icon, or short word, it is still numerical 20 underneath. Changing resin, finish, pattern, glow, tray art, or edge inlay is also presentation-only.

DESIGN PRINCIPLE

Different jobs use different honest tools

Standard RPG dice get physical 3D resolution because those shapes exist in the roller. Arbitrary dN gets a uniform numerical path because pretending every N has a meaningful physical die would be misleading. The interface tells the user which kind of roll is happening.

USE THE TOOL

Roll with the result path visible

Standard dice use the tray; arbitrary dN uses the explicitly labeled secure custom-roll path.

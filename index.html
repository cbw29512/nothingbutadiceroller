FREE TABLETOP DICE TOOLS

Roll first. Learn or customize only when you want to.

Nothing But A Dice Roller is a free browser-based tabletop RPG dice roller built around a simple idea: the main screen should stay fast. Roll standard d4, d6, d8, d10, d12, d20, and percentile d100 with the physical 3D tray, use one-click advantage or disadvantage for d20 checks, or open CUSTOM when you need an unusual numerical die such as d3, d7, d37, or d1000.

The advanced tools stay out of the way until they are useful. Dice Studio can change colors, face symbols, number glow, resin effects, finishes, patterns, and edge inlays without changing the numerical die underneath. Custom dN uses a separate secure numerical path instead of pretending every possible number of sides has a meaningful physical mesh.

D20 RollerFast d20 rolls plus links to advantage and probability tools. Advantage & DisadvantageLearn the keep-highest and keep-lowest d20 pattern. D20 Probability CalculatorCompare normal, advantage, and disadvantage success odds. Custom dN RollerRoll arbitrary numerical dice from d2 through d1,000,000. Custom 3D DiceSee what Dice Studio can change without touching mechanics. All Dice ResourcesGuides for notation, randomness, percentile dice, and TTRPG use.
TRANSPARENT RESULT PATHS

Physical standard dice. Secure arbitrary dN. Visual customization stays visual.

Standard RPG dice use the result returned by the 3D physics roll. Arbitrary custom dN uses browser Web Crypto with rejection sampling for a uniform 1-to-N result. A custom face marking—whether it is a skull, rune, icon, number, or short word—does not rewrite the logical numerical face underneath.

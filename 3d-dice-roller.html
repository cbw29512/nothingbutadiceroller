STANDARD SET

d4 through percentile d100

The physical roller supports the familiar tabletop set: d4, d6, d8, d10, d12, d20, and percentile d100. Choose one or build a mixed pool, then roll the set together.

PHYSICS

Standard dice use the 3D physics result

The visible standard dice are not a decorative animation placed on top of a separately chosen answer. The physics roll supplies the numerical result used by the app. That connection is part of the product's trust model.

CUSTOMIZATION

Change the look without changing the die underneath

Dice Studio can change colors, face markings, glow, clear-resin effects, surface finishes, patterns, and edge inlays. The visual layer never changes the number of sides or the logical numerical result.

FAST ACCESS

No account required to roll

The core roller works in guest mode. Accounts are optional for cloud-backed saved configurations and owned Dice Studio sets; they are not a gate in front of the basic roll.
